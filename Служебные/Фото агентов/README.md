# Фото агентов

Хранилище портретов для «одушевления» агентов — по одной подпапке на сферу жизни
(нумерация совпадает с папками сфер в корне репозитория).

## Формат входящего архива

Пользователь присылает zip-архив с фотографиями. Имя файла внутри архива имеет формат:

```
<номер сферы>.<пол><номер>.<расширение>
```

Например `1.м1.png` — сфера 1 («Система и порядок»), мужской персонаж №1.
`4.ж2.jpg` — сфера 4 («Общение и стиль»), женский персонаж №2.

Пол: `м` — мужской, `ж` — женский.

**Важно при распаковке:** архив может быть упакован без явного UTF-8-флага в именах
файлов — команда `unzip` без указания кодировки может испортить кириллицу в
именах. Распаковывать с `unzip -O UTF-8` (или через `python3 -c "import zipfile; ..."`
и сверять на реальных байтах), прежде чем читать имя файла.

## Что делать при получении нового архива

1. Распаковать архив, для каждого файла прочитать номер сферы и пол из имени.
2. Определить папку назначения — `Фото агентов/<N. Название сферы>/` по номеру.
3. Сгенерировать случайные русские имя и фамилию (мужские — для «м», женские — для «ж»),
   не повторяя уже использованные в этой сфере имена (см. список ниже).
4. Переименовать файл в формат `Имя Фамилия.<расширение>` и сохранить в папке сферы.
5. Дополнить список использованных имён в этом файле.
6. Всем агентам этой сферы, у которых ещё не назначено фото, назначить фото случайным
   образом из всех доступных в папке сферы (включая уже использованные для других
   агентов — одно фото может представлять нескольких агентов, но только внутри своей
   сферы). Записать назначение в раздел «Аватар» файла агента
   (`<сфера>/Агенты/<агент>.md`) — это единственное место, откуда берётся привязка агента
   к фото. Смена фото — только по прямой просьбе пользователя.
