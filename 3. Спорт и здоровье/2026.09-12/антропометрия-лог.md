## Заметки

- Данные с 01.03.2026 по 01.08.2026 получены от пользователя ретроспективно (пришлёт
  ещё часть за более ранний период) — до этого в системе была только точка 01.08.2026.
- Ряд нерегулярный по интервалам (не строго раз в месяц): 01.03 → 11.04 (~6 нед.) → 07.06
  (~8 нед., пропуск) → 12.07 (~5 нед.) → 01.08 (~3 нед.) → 05.09 (~5 нед.).
- Талия/живот: 91 → 92 → 92,3 → 89 → 89 → 89 — заметное снижение произошло между
  07.06 и 12.07 (−3,3 см), затем стабильно на 89 три замера подряд.
- Вес колеблется в диапазоне 67,6–70,1 кг без устойчивого тренда за этот период —
  ожидаемо, целевой режим тренировок ещё не запущен.
- 05.09.2026: замер утром сразу после душа, перед завтраком. Тренировки по новому
  режиму («Тренер-конструктор режима») ещё не начались — эта точка фактически ещё
  часть исходного состояния (точка А), а не результат тренировок.
- «Костные» обхваты (запястье, лодыжка, шея) колеблются в пределах ~1 см от замера к
  замеру — похоже на вариативность самой техники измерения, а не реальные изменения.
  Выводы по этим точкам делать только на длинном ряду.
- Ждём ещё часть данных за более ранний период от пользователя — лог будет дополнен.
