# Лог тренировок

Ведёт: агент «Тренер-конструктор режима» (Кирилл Захаров), сфера «Спорт и здоровье».
Время/день тренировок планирует «Система» (агент «Конструктор дня») — здесь фиксируется
только содержание и факт выполнения.

## Система тренировок (актуально на 2026.09.05)

- **Силовая** — 2 занятия/нед., источник: курс app.anatolyfit.com (программы Fat Burn,
  Legs, Back + Biceps, Chest + Triceps, Core + Abs + доп. программы), плюс «8-Week
  Anatoly Abs Program Guide» (челлендж на пресс, 8 недель, довеском к одной из силовых).
- **Лёгкая атлетика** — 2 занятия/нед., контент от агента (мобильность/аэробика, без
  бега — пока нет дорожки/скакалки).
- **Йога** — 2 занятия/нед., по собственной купленной программе пользователя, агент
  только отмечает день.

Оборудование: сборные гантели/штанга (блины 1,25/1,5/2/2,5 кг ×4 каждого), перекладина,
коврик, валик для спины, вибро-платформа. Травм и ограничений нет.

## Отчёты по тренировкам

_Пока пусто. После каждой тренировки пользователь присылает, что делал (программа/
упражнения, подходы, веса, повторения) — записывается сюда с датой._
