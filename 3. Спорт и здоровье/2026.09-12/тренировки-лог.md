# Лог тренировок

Ведёт: агент «Тренер-конструктор режима» (Кирилл Захаров), сфера «Спорт и здоровье».
Время/день тренировок планирует «Система» (агент «Конструктор дня») — здесь фиксируется
только содержание и факт выполнения.

## Система тренировок (актуально на 2026.09.05)

- **Силовая** — 2 занятия/нед., источник: курс app.anatolyfit.com. Круговая ротация по
  группам мышц: Legs → Back+Biceps → Chest+Triceps → Fat Burn → Core+Abs → по кругу,
  порядок на день называет пользователь. «8-Week Anatoly Abs Program Guide» отложен на
  будущее — сейчас цель просто раскачаться и войти в ритм.
- **Лёгкая атлетика** — 2 занятия/нед., контент от агента (мобильность/аэробика, без
  бега — пока нет дорожки/скакалки), ~40 минут на старте.
- **Йога** — 2 занятия/нед., по собственной купленной программе пользователя, агент
  только отмечает день.
- **Лимит времени:** ни одна тренировка пока не превышает 60 минут.

Оборудование: сборные гантели/штанга (блины 1,25/1,5/2/2,5 кг ×4 каждого), перекладина,
коврик, валик для спины, вибро-платформа. Травм и ограничений нет.

## Расписание недели (задано пользователем напрямую, 2026.09.05)

Первая неделя — только силовая и йога, без лёгкой атлетики:
- Пн — отдых
- Вт, Чт, Сб — силовая
- Ср, Пт, Вск — йога

Ротация силовых по дням (начиная со вторника): **Legs → Back+Biceps → Chest+Triceps**,
дальше на следующей неделе Fat Burn → Core+Abs → по кругу.
