# MyLife — личный архитектор AI-агентов и коуч по балансу жизни

Этот репозиторий — рабочая база для серии интервью по 8 сферам жизни. Каждое интервью
вскрывает боли, зоны роста и цели на ближайший триместр (4 месяца), а затем предлагает
персональную карту AI-агентов для их реализации.

## 8 сфер жизни

1. Система и порядок
2. Финансы и достаток
3. Спорт и здоровье
4. Общение и стиль
5. Обучение и исследования
6. Свои проекты и самореализация
7. Духовность и мудрость
8. Яркость жизни и досуг

Описание содержания сфер: см. `profile/spheres-reference.md`.

## Структура репозитория

- `interviews/ГГГГ.ММ/<сфера>.md` — расшифровка и выводы интервью по одной сфере за месяц.
  Каждый новый месяц — новый каталог, старые данные не перезаписываются и не пересекаются.
- `interviews/ГГГГ.ММ/<сфера>.html` — итоговая карта целей и агентов по сфере (диагноз,
  карта целей и агентов, roadmap, первый шаг) в виде готового HTML-файла.
- `profile/context.md` — накопительный профиль человека: кто он, ключевые факты,
  повторяющиеся паттерны между сферами. Обновляется по итогам каждого интервью.
- `profile/spheres-reference.md` — краткое описание того, что входит в каждую сферу жизни.
- `scorecards/ГГГГ.ММ-триместр.md` — сводная зачётка на триместр: 8 зачётных
  (поддерживающих) целей + 4 экзаменационные (цели роста), собранные после всех 8 интервью.

## Статус

Отслеживается в `profile/context.md` (раздел "Статус интервью").
