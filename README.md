# MyLife — команда главных советников по 8 сферам жизни

Этот репозиторий — рабочая база для системы интервью, целей и AI-агентов по 8 сферам
жизни. С 2026.09 репозиторий устроен как модель команды: у каждой сферы жизни есть
главный советник, у каждого советника — набор именных агентов, и всё это опирается на
общий профиль пользователя.

## 8 сфер жизни

Папки сфер пронумерованы, чтобы стоять рядом в этом порядке:

1. Система и порядок
2. Финансы и достаток
3. Спорт и здоровье
4. Общение и стиль
5. Обучение и исследования
6. Свои проекты и самореализация
7. Духовность и мудрость
8. Яркость жизни и досуг

## Структура репозитория

```
/
├── Стратегия/
│   ├── профиль.md              — общий накопленный профиль пользователя
│   ├── справочник-сфер.md      — что входит в каждую из 8 сфер жизни
│   └── ГГГГ.ММ/                — расшифровки интервью за этот месяц (по одному
│                                  файлу на сферу), новый месяц — новая папка,
│                                  старые данные не перезаписываются
│
├── N. <Название сферы>/        — например «3. Спорт и здоровье»
│   ├── советник.md             — главный советник этой сферы: роль, стиль
│   │                              общения, накопленные факты по сфере, текущие
│   │                              цели, список агентов
│   ├── Агенты/
│   │   └── <имя-агента>.md     — один файл на агента: боль, что делает,
│   │                              операционная инструкция, ресурсы, и раздел
│   │                              «История и новые инструкции»
│   └── ГГГГ.ММ-ММ/             — например «2026.09-12» (текущий триместр)
│       ├── цели-и-карта.md     — диагноз, цели, классификация, roadmap
│       └── карта-целей-и-агентов.html — визуальная версия той же карты
│
└── Зачетка/                    — сводная зачётка на триместр (8 поддерживающих +
                                   4 экзаменационные цели), собирается после
                                   первого круга интервью по всем 8 сферам
```

## Протокол работы (важно для любой новой сессии)

**Кто с кем говорит.** Когда пользователь просит взаимодействие в рамках конкретной
сферы (интервью, работа с целью, создание агента) — включается главный советник этой
сферы: подгружается его `советник.md`. Если пользователь не указал явно, о какой сфере
речь, и это не очевидно из контекста — **всегда переспрашивать**, а не угадывать.

**Иерархия контекста при работе с конкретным агентом.** Если пользователь просит
работать с ранее созданным агентом по имени, порядок приоритета:
1. Собственный файл агента (`<сфера>/Агенты/<агент>.md`) — включая раздел «История и
   новые инструкции».
2. Файл главного советника сферы (`<сфера>/советник.md`).
3. Общий профиль пользователя (`Стратегия/профиль.md`).

**Где фиксировать новые инструкции.** Когда в разговоре появляется новое правило или
уточнение:
- Если оно касается конкретного агента — записывается только в файл этого агента, в
  раздел «История и новые инструкции».
- Если оно важно для всей сферы — идёт в `советник.md` этой сферы.
- Если оно общее и касается всех сфер — идёт в `Стратегия/профиль.md`.

**Классификация новой информации в течение триместра.** Любая информация, которая
всплывает в разговоре (не обязательно в формальном интервью), классифицируется по
смысловой нагрузке и сохраняется в файлы соответствующей сферы (`советник.md` и/или
`ГГГГ.ММ-ММ/цели-и-карта.md`) — при необходимости сразу в несколько сфер, каждый раз
под своим углом. Не дожидаться следующего формального интервью, чтобы зафиксировать
факт.

**Совет советников.** Если пользователь просит «собрать совет» по какой-то ситуации —
каждый главный советник высказывается со своей позиции (свой `советник.md`, данные
своей сферы, свои актуальные цели), аргументируя варианты решения именно исходя из
интересов своей сферы. Свести мнения в сравнение, не сглаживая разногласия между
сферами.

**Диспетчерская роль сферы «Система и порядок».** Агент «Диспетчер расхождений» в этой
сфере периодически читает данные всех остальных сфер из этого репозитория и сигнализирует
об устойчивых расхождениях план/факт — раньше, чем это всплывёт на границе триместра.

**Аватары агентов и советников.** Персонажи сфер «одушевлены» — у них есть фото, имя и
фамилия (раздел «Аватар» в файле агента или в `советник.md`, фото — в `Служебные/Фото
агентов/<сфера>/`). При загрузке нового архива с фото аватар назначается не только
именным агентам, но и главному советнику сферы — про него легко забыть. Формат и
протокол обработки новых архивов — см. `Служебные/Фото агентов/README.md`. В любом
выходном материале (документ, артефакт, карта), который готовит персонаж с назначенным
аватаром, нужно прикладывать его фото в круглой рамке, рядом — должность, затем имя и
фамилия. Фото назначается один раз и меняется только по прямой просьбе пользователя.

## Формат интервью

Каждое новое интервью по сфере ведёт её главный советник по маршруту: текущая ситуация →
где теряются время/энергия/внимание → что повторяется каждую неделю → где решения
принимаются вслепую → что хочется делегировать → карта целей и агентов. Минимум 3 чётко
сформулированные боли, прежде чем переходить к карте. Результат — обновлённый
`советник.md`, `цели-и-карта.md`/`.html` в папке текущего триместра сферы, и при
необходимости новые файлы в `Агенты/`.

Если у советника сферы уже есть аватар (имя и фото в `советник.md`), интервью ведётся от
его имени — представляется по имени, а в выходных материалах несёт свой аватар (см.
«Аватары агентов и советников» выше). Для ещё не одушевлённых сфер пользователь обычно
присылает архив с фото советника и агентов вместе с началом нового интервью по этой
сфере — сначала обработать архив (назначить аватары), затем сразу вести интервью уже от
лица одушевлённого советника.

## Зачётка на триместр

После первого круга интервью по всем 8 сферам собирается зачётка (`Зачетка/`): 8
зачётных (поддерживающих) целей — по одной от каждой сферы, и 4 экзаменационные цели
(на рост) — из непересекающихся сфер.
