# BondKeeper — прогресс по разработке

Сервис мониторинга рисков по облигациям РФ (GitHub: staschern/bondkeeper), совместный
стартап с партнёром. Для самой разработки уже есть отдельный кодовый агент (см.
`../советник.md`) — здесь только журнал фактических спринтов/вех, без техзадач и без
дублирования бэклога партнёра (тот ведёт агент «Бэклог партнёра», см.
`бэклог-партнёра-лог.md`). Контекст проекта и сроки (MVP — октябрь 2026) — в
`../../Стратегия/2026.09/svoi-proekty-i-samorealizatsiya.md` и
`цели-и-карта.md` (Цель #2).
