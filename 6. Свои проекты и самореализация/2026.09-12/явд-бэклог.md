# Бэклог ЯВД (yavdele.com)

Ведёт: агент «Архитектор ЯВД» (Ольга Жукова), сфера «Свои проекты и самореализация».
При еженедельном обращении (по плану — раз в выходные) предлагает один конкретный
следующий шаг с учётом приоритета и доступного времени. Раз в месяц — сводка прогресса.

## Полный бэклог (на 2026.09, без порядка приоритета)

- Редизайн страниц.
- Адаптивная вёрстка под мобильные.
- Устранение недочётов/неточностей.
- Перенос ручных xls-расчётов по капиталу/инвестициям в механизмы сайта (раздел
  «Финансы»).
- Геймификация с советниками по сферам жизни (фото, всплывающие напоминания и мудрые
  мысли каждый день — почта/Telegram и другие каналы).
- Обучающий квест для новых пользователей.
- Тренажёр памяти по карточкам для изучения языков (иероглифы, история ответов, подбор
  вопросов по частотности ошибок).
- MCP-интеграция для работы с ИИ-моделями.
- Двухфакторная аутентификация.
- Публикация страниц для сторонних пользователей.
- **Раздел планирования дня/недели** (добавлено 12.09.2026, пользователь считает — не
  было в бэклоге): просмотр всех 7 дней недели с почасовым расписанием (как в HTML,
  который сейчас готовит Артём — см. «В работе»), ручное редактирование прямо на сайте,
  копирование шаблона существующего дня при создании нового, быстрая загрузка недельного
  расписания через JSON на заданные дни.

  подтверждения, прежде чем фиксировать источник JSON как окончательный.

  **Доступ к репозиторию `staschern/yavdele2`** — подключён 12.09.2026 для понимания
  архитектуры перед проектированием. Находки после быстрого просмотра:
  - Стек: Yii2 (PHP), advanced-шаблон (`common`/`frontend`/`backend`/`console`), MySQL.
  - `common/models/goal/Day.php` (таблица `calendar`) — уже хранит **цвет дня → сфера**

    цвета-дней.md`. Хороший якорь: новые блоки расписания можно опционально привязывать
    к этой же сфере дня для единого цветового оформления, как в HTML-расписании Артёма.
  - `common/models/goal/Task.php` (таблица `task`) — есть `date`, `priority`, `plan`,
    `fact`, `status`, `type`, **но нет поля времени/длительности** — почасового
    расписания в системе пока действительно нет, задача новая, не расширение
    существующего.
  - `GoalController.php` (1647 строк) — большой контроллер модуля `goal`, где живут
    `day`/`calendar`/`task` экшены — новый раздел логично встраивать туда же или
    выносить в отдельный контроллер по аналогии.

  **Черновая архитектура (для обсуждения, не реализовано):**
  1. Новая сущность, например `ScheduleBlock`: `id_user`, `date`, `start_time`,
     `end_time` (или `duration`), `title`, опционально `id_sphere` (для цвета,
     наследуется от дня или переопределяется вручную).
  2. Страница «Неделя»: 7 карточек-дней (по аналогии с HTML-расписанием), каждая — список
     блоков этого дня, с формами добавить/редактировать/удалить блок.
  3. «Скопировать день»: взять все блоки одной даты, создать копии на другую дату.
  4. Импорт JSON на неделю: формат — по одному массиву блоков на каждую из 7 дат, разбор
     и массовое создание `ScheduleBlock`, дальше редактируется вручную как обычно.
