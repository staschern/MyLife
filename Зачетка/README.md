# Зачётка

Здесь появится сводная зачётка на триместр после первого круга интервью по всем 8
сферам жизни: 8 зачётных (поддерживающих) целей — по одной от каждой сферы, и 4
экзаменационные цели (на рост) из непересекающихся сфер.

Пройдено интервью: Яркость жизни и досуг, Общение и стиль, Спорт и здоровье, Система и
порядок (4 из 8, статус — см. `../Стратегия/профиль.md`).
