Сводная зачётка на триместр: 8 зачётных (поддерживающих) целей — по одной от каждой сферы,
и 4 экзаменационные цели (на рост) из непересекающихся сфер.

**Триместр 15 (2026.09-12) собран советом 09.09.2026, зафиксирован 10.09.2026** — см.
`2026.09-12.md`: итоговая зачётка, обоснование выбора 4 целей роста, решения совета по
декомпозиции и контрольным точкам, предварительный план на 4 месяца и справочник по
регулярности взаимодействия с агентами. Полноценный триместр официально стартует
11.09.2026; дальше прогресс по зачётке сверяется каждое воскресенье вместе с недельным
планом.

Первый круг интервью по всем 8 сферам завершён 2026.09.07 (статус — см.
