# Интервью: Свои проекты и самореализация — 2026.09

Дата: 2026-09-05. Провёл: Владимир Панов, главный советник сферы.

## Транскрипт интервью

**В1. Чем занимаешься как основная работа, куда движешься профессионально?**
Старший разработчик 1С в ПЭК (IT-дочка логистической компании), команда автоматизации
бухгалтерских систем. Доход ~160 000 ₽/мес после налогов, стабильно, но без индексации
1-2 года и без повышения уже несколько лет. Компания в кризисе: 3-й гендиректор за
1.5 года, отток сильных сотрудников (в его команде из 3 разработчиков ушло 2, новых не
берут), нагрузка большая. Сам — один из лучших специалистов, уникальные знания систем,
к нему идут за советом даже из поддержки/тестирования. Особых планов роста в этой
компании нет, кроме опыта и признания. Девушка зарабатывает больше (эксперт в IT нефтяной
отрасли, ~200 тыс + премии), но это тема для финансового советника.

**В2. Раз роста не предвидится — действуешь как-то (ищешь вакансии, фриланс), или пока
наблюдение?**
Экспертиза во многом привязана к уникальным системам компании — в другом месте
пришлось бы заново вникать, хотя технический навык (код) универсален. Сейчас
специально ничего не ищет — работа как стабильный доход, «верю, что кризис пройдёт».
Реальный рост (в доходе и навыках) видит в собственном стартапе с другом — есть
бизнес-план, и при удачном сценарии доход может вырасти кратно.

**В3. На какой стадии проект, что тормозит?**
Проект — BondKeeper (сервис мониторинга рисков по облигациям, GitHub:
staschern/bondkeeper). Стадия — разработка до MVP: БД по эмитентам/облигациям и
истории рейтингов 4 агентств заполнена, в разработке — парсинг новостей рейтинговых
агентств. Дальше — интеграция с ФНС (через юрлицо партнёра). MVP с Telegram-ботом
запланирован на октябрь, в ноябре — маркетинг. Тормоза: работа по остаточному
принципу (1-2 часа, 3-4 будних дня + больше по выходным), капча на некоторых
источниках данных, зависимость от партнёра по регистрации юрлица для данных ФНС.
Приложен бизнес-план (июль 2026): целевая аудитория — частные инвесторы в облигации
(100+ тыс. активных ежедневно), 4 тарифа (Free/Basic 890₽/Pro 2990₽/Expert 5990₽),
нужно 4,89 млн ₽ стартового финансирования, окупаемость 35-40 мес., но чистая прибыль
уже во 2-й год.

**В4. Прогресс по срокам плана отстаёт — та же причина, что и разрушенное «магическое
утро» в других сферах, или другое?**
Скорее не то же самое — суммарного остаточного времени не так мало (за ~1 месяц
работы уже заметный прогресс). Магическое утро для этого проекта не используется —
канал времени другой: вечера буднего дня после основной работы плюс выходные. Задача
— планомерно держать этот ритм (1-2 часа в 3-4 будних дня + 3 часа в выходные).

**В5. Что поручил бы идеальному ассистенту для BondKeeper?**
Для самой разработки уже есть отдельный агент, который ускоряет работу — там больше
ничего специально не нужно. Регулярность тоже не проблема — включается по мере
поступления вводных от партнёра. Реальная боль — партнёр присылает задачи/идеи в
хаотичном режиме, часть устаревает ещё до реализации из-за новых вводных. Нужен
агент, который запоминает эти сообщения, а по запросу выдаёт структурированный,
актуальный бэклог с пометкой, что сделано.

Отдельно есть собственные проекты (не общие с партнёром) по убыванию приоритета:
1) ЯВД, 2) обучающий курс по финансовой грамотности/макроэкономике/инвестициям,
3) для души — браузерная стратегия в реальном времени (наподобие Цивилизации).

**В6. По ЯВД — что в бэклоге доработок, сколько времени выделяется?**
Бэклог большой: редизайн страниц, адаптивная вёрстка под мобильные, устранение
недочётов, перенос ручных xls-расчётов по капиталу/инвестициям в механизмы сайта,
геймификация с советниками по сферам жизни (фото, всплывающие напоминания и мудрые
мысли каждый день — почта/Тг и другие каналы), обучающий квест для новых
пользователей, тренажёр памяти по карточкам для языков (иероглифы, история ответов,
подбор по частотности ошибок), MCP для работы с ИИ-моделями, двухфакторная
аутентификация, публикация страниц для сторонних пользователей. Приоритет — после
общего проекта с партнёром, но минимум раз в неделю по выходным — новый шаг. Курс по
финансам — хотя бы раз в месяц в выходной. Игра — пока только формирование концепции.

**В7. Результат-мечта на 4 месяца?**
BondKeeper: октябрь — минимальный работающий продукт, ноябрь — продвижение в
маркетинге и привлечении, первые продажи, декабрь — автоматизация рутины проекта с
помощью ИИ, далее — новые функции по необходимости. ЯВД: реализовать 3-4 явных
новшества из бэклога. Курс: первая подробно написанная глава/статья + прописанный
общий план по крупным разделам курса. По основной работе цели сознательно не ставит.

## Ключевые находки (боли)

1. Основная работа (старший разработчик 1С в ПЭК) тупикова по росту — зарплата не
   индексируется 1-2 года, компания в видимом кризисе (3-й гендиректор за 1.5 года,
   отток сильных кадров) — при этом сам стал незаменимым экспертом, но сознательно не
   предпринимает никаких шагов на этот счёт, держится за стабильность и комфорт.
2. В BondKeeper партнёр присылает задачи/идеи в хаотичном режиме без структуры — часть
   успевает устареть до реализации, нет живого актуального бэклога.
3. У ЯВД (приоритет №1 среди личных проектов) — большой неструктурированный бэклог
   идей без гарантированного регулярного времени на реализацию.
4. Курс по финансовой грамотности заявлен приоритетом №2, но пока нет ни плана по
   разделам, ни начатого контента.
